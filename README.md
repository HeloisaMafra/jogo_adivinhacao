🎮 Jogo de Adivinhação

Um jogo simples desenvolvido em Python, onde o computador sorteia um número de 1 a 10 e o jogador precisa tentar adivinhar qual foi o número escolhido.

🚀 Como funciona
O computador sorteia um número aleatório entre 1 e 10.
O jogador informa seu palpite.
O programa verifica se o número está correto.
O jogador recebe uma mensagem informando se acertou ou errou.

💻 Tecnologias utilizadas
Python
Biblioteca random

▶️ Como executar
Clone este repositório:
git clone https://github.com/HeloisaMafra/jogo_adivinhacao.git
Entre na pasta do projeto:
cd jogo_adivinhacao
Execute o programa:
python main.py
